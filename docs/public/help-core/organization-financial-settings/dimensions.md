# Dimensions

Dimensions define optional analysis labels that can be attached to financial activity across the organization.

## Concepts

* [Financial Document Processing](../../voyzu-core-concepts/financial-document-processing.md) explains the data recorded by financial documents.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains organization standards and company settings.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains company financial separation.

## Viewing dimensions

The list shows each dimension's code, name, sequence, status, and usage state. Search and status filters narrow the list. Open a row to see the dimension and its allowed values. Use sequence to control the order in which dimensions are presented.

## In use

A dimension or value is in use when financial data refers to it. In-use records must remain available so historical activity and reports can still be interpreted.

## Create a new dimension

Select **Add Dimension**, enter a stable code and clear name, and choose its display sequence. Open the new dimension to add the allowed values users can select.

## Make changes

Edit names, sequence, and allowed values from the detail screen. Keep codes stable after use. Adding a value makes it available for later documents; it does not change historical records.

## Change status

Deactivate unused dimensions or values to prevent new selection while preserving history. Reactivate them when they should be selectable again.

## Delete

Delete only records with no references or postings. Prefer deactivation when history exists.
