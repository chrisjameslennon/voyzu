# Ledger Backed Account Codes

The Ledger Backed Account Codes report shows how supporting-ledger purposes map to general ledger accounts.

## Concepts

* [Control Accounts](../../../voyzu-core-concepts/control-accounts.md) explains ledger-backed accounts.
* [What Is a Financial Ledger?](../../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains the general ledger and subledgers.

## Data shown

Each row shows:

* Ledger-backed account code and name
* Supporting ledger
* Linked general ledger code
* Linked general ledger account name

The report combines AP, AR, tax, bank/cash, and inventory control-account mappings and groups them by supporting ledger. Use it to verify that every financial purpose points to the intended GL destination.

## Using the report

Review code, purpose, supporting ledger, and GL account as a single mapping. Use **Options** to control available sections and the organization header. The report uses landscape layout. Refresh after mapping changes, then view or download the PDF.
