# Financial Document Types

The Financial Document Types report lists the document types supported by the financial model.

## Concepts

* [Financial Document Processing](../../../voyzu-core-concepts/financial-document-processing.md) explains document types and posting.
* [What Is a Financial Ledger?](../../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains supporting ledgers.

## Data shown

Each row shows:

* Document type code
* Primary supporting ledger
* Status

Use the report to identify which document codes an API client can submit and the supporting ledger principally affected by each type. It does not show the complete posting definition or account roles.

## Using the report

Use stable document codes in integrations. Open the document type detail for its posting behavior. Refresh after a deployment changes the financial model, then view or download the PDF.
