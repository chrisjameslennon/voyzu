# Inventory Item Posting Codes

The Inventory Item Posting Codes report shows the financial posting mappings held by organization item posting profiles.

## Concepts

* [Inventory](../../../voyzu-core-concepts/inventory.md) explains item posting profiles and financial inventory.
* [Control Accounts](../../../voyzu-core-concepts/control-accounts.md) explains how supporting-ledger activity reaches the GL.

## Data shown

Each profile shows:

* Profile code, name, and description
* Revenue code
* Cost of goods sold code
* Purchase expense code
* Consumption code
* Adjustment gain code
* Adjustment loss code

A dash identifies a posting slot that is not configured. Use the report to compare profiles and confirm that each supported item flow has the expected posting code. It does not show items assigned to the profile or posted values.

## Using the report

Review the detail lines beneath each profile. The report uses landscape layout for the posting slots. Refresh after profile changes, then view or download the PDF.
