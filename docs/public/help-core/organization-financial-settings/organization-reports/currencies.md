# Currencies

The Currencies report lists the monetary units available to the organization.

## Concepts

* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains company base currencies and country defaults.

## Data shown

Each row shows:

* Currency code
* Currency name
* Symbol
* Status

Use the report to confirm the currency identifiers and symbols available for company setup and financial documents. It is reference data only; it does not show exchange rates, conversions, or company balances.

## Using the report

Check codes carefully when reconciling an API client or integration. Refresh after reference-data changes, then view or download the PDF.
