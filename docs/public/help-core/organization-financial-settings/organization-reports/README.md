# Organization Reports

Organization Reports presents printable lists of the organization's companies and financial configuration.

## Concepts

* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains organization-wide records and separate company ledgers.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains how organization standards flow to companies.
* [Control Accounts](../../../voyzu-core-concepts/control-accounts.md) explains ledger-backed account mappings.
* [Inventory](../../../voyzu-core-concepts/inventory.md) explains item categories and posting profiles.

## Available reports

Use these reports to review or share organization setup:

* Companies
* Countries
* Country Tax Settings
* Currencies
* Dimensions
* Financial Document Types
* General Ledger Accounts
* Inventory Categories
* Inventory Items
* Financial Document Defaults
* General Ledger Reporting Categories
* Ledger Backed Account Codes
* Inventory Item Posting Codes

These are configuration lists, not transaction or balance reports. Open the help from an individual report for the exact data it shows.

## Report controls

Use **Options** to show or hide the organization header and any report-specific sections. Refresh after setup changes. Use the PDF controls to view or download the current report presentation.
