# Inventory Items

The Inventory Items report lists the organization's default financial items.

## Concepts

* [Inventory](../../../voyzu-core-concepts/inventory.md) explains financial items, categories, posting profiles, and valuation.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains how organization defaults flow to companies.

## Data shown

Each row shows:

* Item code, name, and type
* Category code and name
* Unit and status

Use the report to review the default items and their assigned categories. Organization items are defaults, so the report does not show quantities, values, or company transactions. The Inventory Categories report shows the posting profile selected by each category.

## Using the report

Select **Show inactive Inventory Items** to include inactive defaults. Refresh after item maintenance, then view or download the PDF.
