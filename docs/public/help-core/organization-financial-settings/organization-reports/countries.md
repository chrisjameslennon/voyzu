# Countries

The Countries report lists the country reference data available to the organization.

## Concepts

* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains localization.
* [Tax](../../../voyzu-core-concepts/tax.md) explains why country configuration controls tax behavior.

## Data shown

Each row shows:

* Country code and name
* Default currency
* Tax authority
* Status

Use the report to see which country, currency, and tax-authority combinations are available when companies are created. The report does not show the detailed tax rules, components, rates, or filing settings held on the country detail screen.

## Using the report

Review active countries before company setup or localization changes. Refresh after configuration is updated, then use the PDF controls to view or download the list.
