# Companies

The Companies report lists the financial entities held by the organization.

## Concepts

* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains the organization-to-company model.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains shared organization settings.

## Data shown

Each row shows:

* Company code and name
* Report line 1 and report line 2
* Country
* Base currency
* Status

Use the report to review the organization's company register and the names and report text that will identify each entity in financial output. It does not combine company balances or transactions.

## Using the report

Check that codes remain stable, countries and currencies match the intended ledgers, and inactive companies are expected. Refresh after changing a company. Use **Options** to control the organization header, then view or download the PDF.
