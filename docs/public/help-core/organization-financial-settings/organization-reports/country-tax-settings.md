# Country Tax Settings

The Country Tax Settings report shows the tax configuration available to financial documents for each country.

## Viewing the report

Each country is a separate section containing its configured:

* tax authorities;
* tax rules; and
* tax rule lines, including their rates and receiving authorities.

Active countries are shown by default. Select **Show inactive Countries** to include inactive countries. A country without tax configuration is shown with a clear empty state.

## Using the data

Use this report to review how country tax rules resolve into one or more tax rule lines when financial documents are posted. The report is configuration data; it does not show tax transactions or balances.
