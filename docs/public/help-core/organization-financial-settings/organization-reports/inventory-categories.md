# Inventory Categories

The Inventory Categories report lists the organization's default financial item categories.

## Concepts

* [Inventory](../../../voyzu-core-concepts/inventory.md) explains financial items, categories, posting profiles, and valuation.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains copied company defaults.

## Data shown

Each row shows:

* Category code and name
* Description
* Posting profile code and name
* Status

Use the report to review the categories that organize organization items and the posting profile inherited by each category's items. Categories are copied when a company is created. The report does not show inventory balances.

## Using the report

Check that category codes and descriptions are distinct and meaningful. Refresh after category maintenance, then view or download the PDF.
