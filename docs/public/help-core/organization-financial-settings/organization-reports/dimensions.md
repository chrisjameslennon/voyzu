# Dimensions

The Dimensions report lists the organization's financial analysis dimensions.

## Concepts

* [Financial Document Processing](../../../voyzu-core-concepts/financial-document-processing.md) explains how dimensions can accompany financial activity.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains organization standards.

## Data shown

Each row shows:

* Dimension code
* Dimension name
* Status

Use the report to review which dimensions are available as organization standards. The list does not expand the allowed values within each dimension or show transaction usage.

## Using the report

Confirm that active dimension codes have clear, stable meanings. Open the dimension setup for values and usage information. Refresh before viewing or downloading the PDF.
