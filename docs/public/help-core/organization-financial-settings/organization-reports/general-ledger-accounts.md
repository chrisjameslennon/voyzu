# General Ledger Accounts

The General Ledger Accounts report lists the organization's standard chart of accounts.

## Concepts

* [What Is a Financial Ledger?](../../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains the general ledger.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains organization standard accounts.

## Data shown

Each row shows:

* Account code and name
* Account type
* Reporting category
* Status

Use the report to review account classification and reporting structure. It does not show balances, postings, usage state, or company-specific accounts.

## Using the report

Check that every active account has the intended type and reporting category. Open the account setup to investigate usage or make changes. Refresh before viewing or downloading the PDF.
