# General Ledger Reporting Categories

The General Ledger Reporting Categories report lists the groups used to present general ledger accounts.

## Concepts

* [What Is a Financial Ledger?](../../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains the accounts summarized in financial reporting.
* [Organizations and Companies](../../../voyzu-core-concepts/organizations-and-companies.md) explains organization reporting standards.

## Data shown

Each row shows:

* Category code and name
* Financial statement section
* Account type
* Status

Use the report to review how accounts are grouped into report sections. It does not show category sequence, member-account balances, or a rendered balance sheet or profit and loss statement.

## Using the report

Confirm that each category's section and account type agree. Use the General Ledger Accounts report to see account assignments. Refresh before viewing or downloading the PDF.
