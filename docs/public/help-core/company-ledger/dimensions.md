# Dimensions

Dimensions manages the selected company's analysis labels and their allowed values.

## Concepts

* [Financial Document Processing](../../voyzu-core-concepts/financial-document-processing.md) explains the data captured on documents.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains shared and company settings.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains company scope.

## Viewing dimensions

The list shows dimension code, name, sequence, status, and usage. Search and status filters narrow the list. Open a dimension to inspect and maintain its allowed values.

## In use

A dimension or value is in use when financial data refers to it. Preserve used records so historical analysis remains intelligible.

## Create a new dimension

Select **Add Dimension**, enter a stable code and name, and choose its sequence. Open it to add the values users may select on financial documents.

## Make changes

Update names, sequence, and allowed values from detail. Adding values affects later selection only; it does not classify old entries automatically.

## Change status

Deactivate unused dimensions or values to prevent new selection while retaining history.

## Delete

Delete only dimensions and values with no references. Prefer deactivation where history exists.
