# Financial Document Types

Financial Document Types is the selected company's read-only catalogue of supported posting documents.

## Concepts

* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains organization standards and company-owned settings.
* [Financial Document Processing](../../voyzu-core-concepts/financial-document-processing.md) explains how settings drive posting.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains company scope.

## Selecting the data

Search or filter by purpose, supporting ledger, or status. The list shows code, name, purpose, ledger, and status.

## Reading the detail

Open a type and use its Posting and Details views to understand the business purpose, supported ledger behavior, and account roles. Codes and posting semantics are application-defined.

## Source and scope

Document types are not created or edited on this screen. They are supplied by Voyzu's financial model and exposed to API clients and integrations.

## Refresh and export

Refresh before relying on recently posted activity. Export where the screen offers it, and record the selected company and filters with any output used as evidence.

## Corrections

This is an enquiry screen. Do not try to alter a ledger result here. Correct the source setup where appropriate, or post a supported correcting document or reversal so the financial and audit histories remain complete.
