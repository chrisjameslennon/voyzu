# Audit Log

The Company Audit Log is the read-only mutation history for the selected company.

## Concepts

* [Users and permissions](../../help-platform/settings/users.md) explains user identity and company access.
* [Organizations and Companies](../../voyzu-core-concepts/organizations-and-companies.md) explains company scope.
* [What Is a Financial Ledger?](../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains financial immutability.

## Selecting the data

Filter by date, entity, action, user, or other available fields. Each row identifies the event, timestamp, affected record, mutation, and user.

## Reading the detail

Open an event to compare its before-and-after data or change set. Read the entity identity and event timestamp with the field changes; an isolated value may lack essential context.

## Source and scope

Audit events cannot be changed or deleted. Correct the underlying setup in its own screen, and correct financial activity with a reversal or new document.

## Refresh and export

Refresh before relying on recently posted activity. Export where the screen offers it, and record the selected company and filters with any output used as evidence.

## Corrections

This is an enquiry screen. Do not try to alter a ledger result here. Correct the source setup where appropriate, or post a supported correcting document or reversal so the financial and audit histories remain complete.
