# Inventory Control Accounts

Inventory Control Accounts shows how the selected company's inventory ledger purposes point to general ledger accounts.

## Concepts

* [Inventory](../../voyzu-core-concepts/inventory.md) explains financial items, posting profiles, and valuation.
* [What Is a Financial Ledger?](../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains immutable entries and subledgers.
* [Control Accounts](../../voyzu-core-concepts/control-accounts.md) explains the inventory-to-GL mapping.

## Selecting the data

The screen lists inventory control purposes, their linked GL accounts, required account types, and posting state.

## Reading the detail

Use the mapping to understand where inventory value and related financial movements appear in the GL. **Has postings** marks a relationship already used by company activity.

## Making changes

Open the control account and select an active **Asset** GL account. The mapping cannot be changed after it has postings. Companies using organization standard settings must change the mapping at organization level.

## Refresh and export

Refresh before relying on recently posted activity. Export where the screen offers it, and record the selected company and filters with any output used as evidence.

## Corrections

This is an enquiry screen. Do not try to alter a ledger result here. Correct the source setup where appropriate, or post a supported correcting document or reversal so the financial and audit histories remain complete.
