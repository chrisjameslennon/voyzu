# Inventory Ledger Entries

Inventory Ledger Entries shows item quantity and financial-value movements for the selected company.

## Concepts

* [Inventory](../../voyzu-core-concepts/inventory.md) explains financial items, posting profiles, and valuation.
* [What Is a Financial Ledger?](../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains immutable entries and subledgers.
* [Control Accounts](../../voyzu-core-concepts/control-accounts.md) explains the inventory-to-GL mapping.

## Selecting the data

Search and filter by item, document, date, movement type, or other available fields. The list shows the financial movements used to derive quantity on hand and book value.

## Reading the detail

Open an entry to inspect its source document, item, quantity, unit value, total value, posting profile, valuation context, and linked journal. Read related movements in date order when explaining weighted-average cost.

## Source and scope

Inventory balances are derived from these entries. Voyzu does not use this screen for serial numbers, warehouse locations, bins, or operational stock moves.

## Refresh and export

Refresh before relying on recently posted activity. Export where the screen offers it, and record the selected company and filters with any output used as evidence.

## Corrections

This is an enquiry screen. Do not try to alter a ledger result here. Correct the source setup where appropriate, or post a supported correcting document or reversal so the financial and audit histories remain complete.
