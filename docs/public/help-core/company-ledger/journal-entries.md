# Journal Entries

Journal Entries is the read-only general ledger history for the selected company.

## Concepts

* [What Is a Financial Ledger?](../../voyzu-core-concepts/what-is-a-financial-ledger.md) explains immutable entries, reversals, and subledgers.
* [Financial Document Processing](../../voyzu-core-concepts/financial-document-processing.md) explains how source documents create ledger records.

## Selecting the data

The list shows journal number, posting date, source document and ID, memo or description, line count, amount, and status. Search by the visible identifiers and descriptions, then open a row to inspect its lines.

## Reading the detail

The detail identifies the source document and shows the balanced debit and credit lines, accounts, amounts, and available dimension or narrative context. Follow the document ID back to the originating business event when investigating.

## Source and scope

A journal is produced by posting a financial document. It is evidence of the posting result, not a data-entry screen.

## Refresh and export

Refresh before relying on recently posted activity. Export where the screen offers it, and record the selected company and filters with any output used as evidence.

## Corrections

This is an enquiry screen. Do not try to alter a ledger result here. Correct the source setup where appropriate, or post a supported correcting document or reversal so the financial and audit histories remain complete.
