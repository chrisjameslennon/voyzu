# Introduction

Voyzu Finance provides financial ledger capabilities, including:

* Country and tax settings management
* Financial ledger capabilities, including:
  * General Ledger
  * Accounts Receivable Subledger
  * Accounts Payable Subledger
  * Taxation
  * Inventory Ledger

## Installation

Voyzu must be installed and configured before installing Voyzu Finance. See [Production installation and setup](https://voyzu.gitbook.io/docs/installation-and-operation/installation-and-setup) for the Voyzu installation instructions.

From the root of the installed Voyzu instance, run:

```shell
npm run voyzu:install https://github.com/chrisjameslennon/voyzu-packages.git @voyzu/finance
```
