# Contributing

Where you look to add value technically will depend on the area in which you are looking to contribute:

## Bugs including Accounting Logic errors

If you have spotted a bug in the product, or you do not agree with the Accounting Logic used for a given transaction type, please raise a bug report in Github

## Additional Functionality within the core product

At this stage we are not accepting code contributions within the core (existing) product. If you think there is functionality that would benefit the core product then we would love to hear from you. Please raise a "Core Functionality Extension" issue in Github.

## Developing a Package

If you have a package in mind that would extend the core product then we would welcome product extension.. If you are looking to do this we recommend:

* Become familiar with the Rapid Application Development (RAD) Framework aspects of Voyzu by developing a small module. See [Voyzu Platform Guide](https://app.gitbook.com/s/lZVU6z5SbVuWuzzcOsuF/voyzu-platform-guide "mention")
* Take a look at the [roadmap.md](roadmap.md "mention")
